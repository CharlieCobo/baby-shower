# baby-shower

Proyecto con Vite, React, Zustand, Firebase y Tailwind CSS.

## Puesta en marcha

1. Instala las dependencias:

   ```bash
   npm install
   ```

2. Copia `.env.example` a `.env.local` y rellénalo con la configuración web de tu proyecto de Firebase.

3. Arranca el servidor de desarrollo:

   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev`: servidor de desarrollo
- `npm run build`: build de producción
- `npm run preview`: previsualiza el build
- `npm run lint`: linter (oxlint)
